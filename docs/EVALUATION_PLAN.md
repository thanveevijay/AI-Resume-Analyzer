# Evaluation Plan

Build a consented, human-reviewed evaluation set with resumes and job descriptions from multiple role families. Remove personal identifiers before annotation.

Measure:
- Precision and recall of skill detection.
- False-positive rate for ambiguous skill terms.
- Recall of relevant synonyms.
- Agreement between system evidence and human reviewers.
- Stability of results under formatting changes.

Do not evaluate the tool using hiring outcomes as a proxy for candidate quality. Report limitations and subgroup performance only where data collection is ethical, lawful, and statistically meaningful.
