# Role-Specific Taxonomies

Different job families require different skill vocabularies. A single global list can produce misleading comparisons.

Suggested taxonomy files:
- Software engineering: languages, frameworks, testing, APIs, databases, systems.
- Data analytics: SQL, spreadsheets, BI, statistics, Python, data modeling.
- Machine learning: model families, evaluation, feature engineering, deployment.
- Cloud/data engineering: cloud services, orchestration, distributed processing, warehousing.

Use the JSON taxonomy loader to maintain separate role-specific vocabularies. Document synonyms and ambiguous terms explicitly.
