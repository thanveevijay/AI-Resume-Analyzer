# User Stories

- As a candidate, I want to compare my resume with a specific job description so I can identify relevant evidence.
- As a candidate, I want to see matched and missing terms separately so I can review them.
- As a reviewer, I want the score methodology to be visible so I can understand its limits.
- As a privacy-conscious user, I want local processing and clear retention behavior.

These stories describe assistance and self-review, not automated candidate selection.
