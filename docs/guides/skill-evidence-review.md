# Skill Evidence Review

A keyword match is only a candidate signal. Review the surrounding sentence before treating it as evidence.

## Review checklist
- Is the skill used in a project, role, or certification context?
- Does the sentence describe hands-on work or merely a desired skill?
- Is the term negated or part of an unrelated phrase?
- Is the evidence recent enough for the target role?
- Can the candidate explain the example in an interview?

Show evidence snippets so users can verify every important match.
