# Error Catalog

- File not found: verify the local path and permissions.
- Unsupported file type: use TXT, PDF, or DOCX.
- Missing optional dependency: install the relevant package from requirements.
- Short input: confirm the resume and job description contain extractable text.
- Invalid taxonomy: check that the JSON object maps category names to arrays of strings.

Errors should remain actionable without exposing sensitive file contents.
