# Human Review Workflow

1. Confirm the uploaded document was parsed correctly.
2. Inspect matched skills and the evidence snippets.
3. Check missing terms for synonyms or equivalent experience.
4. Review project and experience bullets for factual clarity.
5. Ignore any suggestion that does not reflect genuine experience.
6. Treat the numeric score as a rough checklist, not a hiring outcome.

The candidate remains responsible for the accuracy of the final resume.
